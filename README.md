# MafoyoThink

Aplikasi edukasi dan alat bantu berpikir yang sedang dikembangkan.

## Branch strategy

- `main` — rilis APK stable.
- `pre/apk` — rilis APK preview.
- `fix/Code` — perbaikan bug dan error.
- `UP/System&UI` — pengembangan sistem dan antarmuka.

## Development

Source code, dokumentasi, build configuration, dan workflow rilis akan ditambahkan bertahap setelah struktur aplikasi difinalkan.
